# Decision log 

When project decisions are made they can be added to the decision log. This is a record of the thinking as the project evolves. Focus on recording decisions which someone joining the project might need to know. 

It can be informal/note form. However, **do not include information which cannot be made public.**

Order in reverse chronological order i.e. most recent decisions should be at top of file. Include dates formatted as YYYY-MM-DD.
